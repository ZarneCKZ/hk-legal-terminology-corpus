Classification rules for rendering multiplicity

譯名多樣性的分類規則

Explorer Report Codebook AI Use Declaration

How to read this codebook

使用說明

Each entry is one English legal term and its Chinese rendering. The category states how many distinct Chinese renderings that English term has across the full official glossary (73,443 records).

每一條是一個英文法律術語及其中文譯名。分類表示該英文術語在完整官方詞庫 （73,443 條）中一共有多少種不同中文譯名。

A rendering with a cross-reference note such as ※比較 is stripped before counting, so only genuinely different renderings are counted; for example, 法律行動 ※比較 suit and 法律行動 count as the same.

帶「※比較」之類交叉引用注記的譯名，計數前會先去掉注記，只算真正不同的譯文； 例如「法律行動 ※比較 suit」和「法律行動」算同一種。

1. one_to_one — One-to-one

1. 一對一（One-to-one）

Definition: The same English legal term has exactly one Chinese rendering across the whole official glossary.

定義：同一個英文法律術語，在整個官方詞庫裡只有一種中文說法。

Theory: Šarčević (1997), New Approach to Legal Translation; Cao (2007), Translating Law.

理論來源：Šarčević（1997）《New Approach to Legal Translation》；Cao（2007）《Translating Law》。

Decision rule: Count the distinct Chinese renderings for this English term across all 73,443 records; if the count is 1, it is one_to_one.

判定規則：數一下這個英文詞在全部 73,443 條官方記錄裡出現過幾種不同的中文譯名；只有 1 種，就歸一對一。

Positive example: abandonment of claim → 放棄申索 (1 rendering).

正例：abandonment of claim → 放棄申索（1 種）

Negative example: at par → 3 renderings, so it is not one_to_one.

反例：at par → 有 3 種譯法，不屬此類。

Boundary case: If the only rendering carries a trailing ※比較 note, the note is stripped first; if the cleaned set still has exactly 1 rendering, it stays one_to_one.

邊界案例：如果一條譯文後面帶了「※比較」之類的交叉引用注記，計數前先把注記去掉，只算真正不同的譯文；去掉後仍然只有 1 種的，才歸一對一。

2. one_to_many — One-to-two-or-three (2–3)

2. 一對二或三（One-to-many, 2–3）

Definition: The same English term is rendered in 2 or 3 different ways in the official glossary.

定義：同一個英文詞，官方給了 2 到 3 種不同的中文譯法。

Theory: Šarčević (1997) on terminological incongruency; Cabré (1999), Terminology.

理論來源：Šarčević（1997）論術語不一致；Cabré（1999）《Terminology》。

Decision rule: Count the distinct Chinese renderings for this English term across all 73,443 records; if the count is 2 or 3, it is one_to_many.

判定規則：數一下這個英文詞在全部 73,443 條官方記錄裡的不同中文譯名數目；是 2 或 3 種，就歸一對二或三。

Positive example: at par → 以票面值 / 按面值 / 照票面值 (3 renderings); action → 行動 / 法律行動 / 訴訟 (3 renderings after the ※比較 note is merged).

正例：at par → 以票面值 / 按面值 / 照票面值（共 3 種）；action → 行動 / 法律行動 / 訴訟（去掉「※比較」注記後共 3 種）

Negative example: abandonment of claim → 1 rendering, so it is not one_to_many.

反例：abandonment of claim → 只有 1 種，不屬此類。

Boundary case: action has a rendering 法律行動 ※比較 suit that looks like a 4th rendering but is only a cross-reference note; after stripping it the count is 3, so the term belongs here rather than in polysemous.

邊界案例：像 action 這種，原文有一條「法律行動 ※比較 suit」，乍看像第 4 種譯法，其實只是同一譯文的交叉引用注記；去掉注記後是 3 種，所以歸一對二或三，而不是一對四及以上。

3. polysemous — One-to-four-or-more (4+)

3. 一對四及以上（Highly polysemous, 4+）

Definition: The same English term is rendered in 4 or more different ways — the clearest case of disagreement.

定義：同一個英文詞，官方有 4 種甚至更多中文譯法，分歧最明顯。

Theory: Cao (2007) on the indeterminacy of legal translation equivalents; Cabré (1999) on polysemy.

理論來源：Cao（2007）論法律翻譯對應詞的不確定性；Cabré（1999）論多義。

Decision rule: Count the distinct Chinese renderings for this English term across all 73,443 records; if the count is 4 or more, it is polysemous.

判定規則：數一下這個英文詞在全部 73,443 條官方記錄裡的不同中文譯名數目；是 4 種或以上，就歸一對四及以上。

Positive example: information → 信息 / 告發 / 情報 / 消息 / 資料 / 資訊 (6 renderings).

正例：information → 信息 / 告發 / 情報 / 消息 / 資料 / 資訊（共 6 種）

Negative example: at par → 3 renderings, so one_to_many; action → 3 renderings after the cross-reference note is merged, so one_to_many.

反例：at par → 只有 3 種，屬一對二或三；action → 去掉交叉引用注記後只有 3 種，也屬一對二或三。

Boundary case: A term with 4 renderings where one is a ※比較 cross-reference note; after stripping it the count is 3, so the term moves to one_to_many. This is how action and statute are handled.

邊界案例：如果一個詞有 4 種譯法，但其中一種是帶「※比較」的交叉引用注記，去掉後只剩 3 種，就改歸一對二或三；這正是 action 和 statute 的處理方式。

Revision log

修訂日誌

v0.1 (draft) — translation strategy, 4 categories: literal, functional equivalent, explanatory, other / mixed. Theory: Vinay & Darbelnet, Cao, Šarčević.

Pilot: the 4 categories were applied to the first 30 sampled entries.

Problem found: the strategy categories could not be applied consistently. An automated first pass agreed with only 14 of the 30 manual pilot labels, mainly because many established Chinese legal terms are themselves calques (e.g. patent agent → 專利代理人), which blurs the line between literal and functional equivalent.

v1.0 — rendering multiplicity, 3 categories: one-to-one (1 rendering), one-to-two-or-three (2–3), one-to-four-or-more (4+). Decision rule: count the distinct Chinese renderings for each English term across the full official glossary (73,443 records). Reason: the rule is mechanical, fully reproducible and consistent, and it directly answers the research question.

Result: all 550 entries classified — one-to-one 367, one-to-two-or-three 139, one-to-four-or-more 44.

v1.1 (current) — cross-reference note fix: a rendering with a trailing ※比較 annotation is no longer counted as a separate rendering; the annotation is stripped before counting. This moved action and statute from one-to-four-or-more to one-to-two-or-three (4 → 3 distinct renderings). Result: one-to-one 367, one-to-two-or-three 141, one-to-four-or-more 42.

v0.1（初稿）— 翻譯策略 4 類：直譯、慣用對等、解釋性、其他/混合。理論來源：Vinay & Darbelnet、Cao、Šarčević。

試標：先把這 4 類用在抽樣的前 30 條上。

發現問題：這 4 類難以一致地套用。自動初判只和人工標記的 30 條對上 14 條，主要因為很多中文法律慣用詞本身就是仿造詞（例如 patent agent → 專利代理人），使「直譯」和「慣用對等」的界線模糊。

v1.0 — 譯名多樣性 3 類：一對一（1 種）、一對二或三（2–3 種）、一對四及以上（4 種或以上）。判定規則：統計每個英文詞在完整官方詞庫（73,443 條）中的不同中文譯法數目。改動原因：規則機械、可完全重現、分類一致，而且直接回答研究問題。

結果：550 條全部完成分類——一對一 367、一對二或三 139、一對四及以上 44。

v1.1（現行）— 交叉引用注記修正：帶「※比較」注記的譯名不再單獨算作一種譯法，計數前先去掉注記。這使 action 和 statute 由一對四及以上改為一對二或三（4 → 3 種）。結果：一對一 367、一對二或三 141、一對四及以上 42。
